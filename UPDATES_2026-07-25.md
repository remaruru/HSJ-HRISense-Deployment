## Summary of Changes

This session focused on polishing the **Employee Directory** (`EmployeesPage`), improving the **Employee Onboarding** flow, hardening the **Employee Service** backend filtering, and upgrading the **seed script** with a massive dataset expansion.

## 🔧 Backend — API

### `apps/api/src/index.ts`
- Minor cleanup: ensured all registered API route prefixes are consistent and correct.
- Rate limiter is set to skip entirely in `development` mode for friction-free local dev.

---

### `apps/api/src/services/employee.service.ts`
- **Extended `list()` filter parameters** to include:
  - `employmentState` — filter by ACTIVE / RESIGNED / TERMINATED / RETIRED / ON_LEAVE
  - `supervisorAssignmentStatus` — filter by ASSIGNED / PENDING / UNASSIGNED
  - `supervisorAssignmentSource` — AUTOMATIC / MANUAL_OVERRIDE / NO_SUPERVISOR_ROLE
  - `hireDateFrom` / `hireDateTo` — date range filter for hire date
  - `accountStatus` — ACTIVE / INACTIVE / NO_ACCOUNT
  - `isArchived` — `true` / `only` / `all` / default active-only
- **SUPERVISOR tier** now respects all of the above filters as well (not just HR FULL tier).
- **`profileCompletion`** is computed and injected into every employee list/detail response:
  - Personal Info (20%), Contact (15%), Employment (25%), Government IDs (15%), Emergency Contact (10%), Documents/Photo (15%)
- **`sortBy` support**: `employeeNumber`, `firstName`, `lastName`, `hireDate`, `employmentStatus`, `employmentState`, `jobRole`, `department`, `unit`, `supervisor`, `profileCompletion`
- Export limit raised to **5,000** records (`limit === 5000` bypass for export calls).

---

### `apps/api/src/scripts/seed_dev_accounts.js`
- **Massively expanded** seed script:
  - Now seeds a realistic org structure with multiple departments, units, job roles.
  - Creates a **large pool of employees** with varied names, hire dates, employment states, and statuses.
  - Dev accounts include HR Admin, Supervisors, and Standard employees for role-based testing.
  - All seeded employees have consistent supervisor resolution run against them.
  - Passwords hashed using `bcrypt`.
  - Script is idempotent — safe to re-run without duplicate errors.

## 🖥️ Frontend — Web

### `apps/web/src/pages/Employees/EmployeesPage.tsx`
Major feature additions to the Employee Directory:

#### ✅ Column Visibility Toggle
- New **"Columns" dropdown button** in the toolbar (with Filter icon).
- Allows toggling visibility of any column: Employee, Job Role, Department, Unit, Supervisor, Status, State, Account, Date Hired, Completion.
- Uses TanStack Table's `getToggleVisibilityHandler()` — state is per-session.
- Skeleton loading and empty-state `colSpan` now use `table.getVisibleLeafColumns().length` so they always match visible column count.

#### ✅ Improved Export Dropdown (PDF & CSV)
- Export menu reorganized into **clearly labeled sections**: "Excel Workbook (.xlsx)", "PDF Document (.pdf)", "CSV (.csv)".
- Each section header is visually separated with a border divider and bold uppercase label.
- All export buttons now have `cursor-pointer` class for correct pointer behavior.
- "Selected (N)" export option correctly appears only when rows are selected.

#### ✅ Advanced Filter Panel Reset Fix
- "Reset Filters" button in the Advanced Filters panel now also clears:
  - `searchInput` + `debouncedSearch` (the main search bar)
  - `employmentStateFilter`
  - `supervisorStatusFilter`
- Ensures a truly clean slate on reset.

#### ✅ Miscellaneous Polish
- Consistent cursor and hover states across dropdown items.
- `colSpan` values in loading/error/empty rows now correctly reflect visible columns.
